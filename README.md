A static, responsive personal portfolio designed for GitHub Pages.

## Files
- `index.html` — main portfolio page
- `style.css` — responsive styling
- `script.js` — small navigation enhancement
- `assets/Srinivasan-Resume.pdf` — resume used on the site

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `srinivasan-portfolio`.
2. Upload all files and folders from this project.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the Pages address.
7. Optional: add a custom domain under **Settings → Pages → Custom domain**.

## Before publishing
